# flowerpower-cms-security-project

This project was developed and deployed locally using MAMP. To set up properly, place the WordPress files in the MAMP/htdocs directory and import the database with phpMyAdmin.
To test mail functionality, MailPit was set up as a local SMTP server and configured with the ‘WP Mail SMTP’ Wordpress mail plugin.
To test payment functionality, Stripe payment getaway plugin was implemented in test mode.
